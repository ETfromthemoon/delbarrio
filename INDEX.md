# 📖 Documentación del Proyecto - Del Barrio Valparaíso Rediseño

## Índice de Documentos

Bienvenido al proyecto de rediseño de la carta digital de Del Barrio Valparaíso. Esta carpeta contiene toda la documentación necesaria para ejecutar el proyecto.

---

## 📚 Los 5 Documentos Principales

### 1. 📖 **[README.md](./README.md)** — Comandos y Estructura
- **Propósito**: Guía técnica y operacional
- **Para quién**: Desarrolladores, Project Manager
- **Contiene**:
  - Estructura de carpetas del proyecto
  - Comandos npm y desarrollo
  - Stack tecnológico
  - Fases de desarrollo
  - Roles y responsabilidades

**Lee primero si**: Necesitas entender cómo está organizado técnicamente el proyecto.

---

### 2. 💼 **[BRIEF.md](./BRIEF.md)** — Negocio, Público, Oferta y CTA
- **Propósito**: Propuesta comercial y estrategia
- **Para quién**: Product Manager, Design Lead, Marketing
- **Contiene**:
  - Descripción del negocio
  - Público objetivo (3 segmentos)
  - Propuesta de valor
  - Call-to-action (CTAs)
  - Mensajería y branding
  - Métricas de éxito

**Lee primero si**: Necesitas entender la estrategia comercial y quién es tu usuario.

---

### 3. ✅ **[DECISIONES.md](./DECISIONES.md)** — Acuerdos que No Se Reabrirán
- **Propósito**: Fijar límites y evitar cambios de scope
- **Para quién**: Todos los stakeholders
- **Contiene**:
  - 20 decisiones cerradas (no negociables)
  - 15 exclusiones explícitas (qué NO se hará)
  - Tech stack definitivo
  - Requisitos de v1
  - Vigencia y proceso de cambios

**Lee primero si**: Necesitas saber qué está decidido y no puede cambiar.

---

### 4. 📚 **[REFERENCIAS.md](./REFERENCIAS.md)** — Evidencia y Patrones
- **Propósito**: Documentar análisis y patrones validados
- **Para quién**: Diseñadores, Desarrolladores, QA
- **Contiene**:
  - Auditoría del sitio actual
  - Análisis de competencia
  - Inventario completo (73 platos)
  - Patrones de UX recomendados
  - Sistema de diseño (tokens)
  - URLs validadas
  - Casos de uso detallados

**Lee primero si**: Necesitas datos, evidencia y patrones de diseño.

---

### 5. ✏️ **[TAREAS.md](./TAREAS.md)** — Siguiente Resultado Verificable
- **Propósito**: Roadmap ejecutable con tareas específicas
- **Para quién**: Equipo de desarrollo, Project Manager
- **Contiene**:
  - 4 Fases de desarrollo (8 semanas)
  - 20 tareas detalladas
  - Resultados verificables
  - Criterios de aceptación
  - Timeline y milestones
  - Métricas de éxito
  - Definition of Done

**Lee primero si**: Necesitas ejecutar el proyecto semana a semana.

## 🎯 Cómo Navegar Este Proyecto

### Por Rol

#### 👨‍💼 **Product Manager**
1. Lee [BRIEF.md](./BRIEF.md) - Entiende la estrategia
2. Valida [DECISIONES.md](./DECISIONES.md) - Confirma los acuerdos
3. Consulta [TAREAS.md](./TAREAS.md) - Gestiona timeline

#### 🎨 **Design Lead**
1. Lee [BRIEF.md](./BRIEF.md) - Entiende la propuesta
2. Consulta [REFERENCIAS.md](./REFERENCIAS.md) - Estudia patrones y design system
3. Ejecuta Fase 1 de [TAREAS.md](./TAREAS.md) - Wireframes y diseño

#### 👨‍💻 **Frontend Developer**
1. Lee [README.md](./README.md) - Entiende la estructura técnica
2. Valida [DECISIONES.md](./DECISIONES.md) - Confirma tech stack
3. Consulta [REFERENCIAS.md](./REFERENCIAS.md) - Estudia patrones UI
4. Ejecuta [TAREAS.md](./TAREAS.md) - Construye componentes

#### 🧪 **QA / Testing**
1. Consulta [REFERENCIAS.md](./REFERENCIAS.md) - Entiende casos de uso
2. Lee [DECISIONES.md](./DECISIONES.md) - Qué está en scope
3. Ejecuta tests de [TAREAS.md](./TAREAS.md) - Fase 3 y 4
